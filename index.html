ℹ️ About the Project

Movie Recommendation System

The Movie Recommendation System is a web-based mini project that helps users discover movies according to their interests.

The user selects a preferred genre such as Action, Family, Education or Sports. The system compares the selected preference with available movie information and displays matching movies.
